# APE2601

Сайт с 3D-долиной цветов и кнопкой «Расписание»: по клику играет звук и открывается стеклянное окно (стиль iOS 26) с расписанием на неделю по времени Астаны. Дни листаются стрелками, вкладками, клавишами ← → и свайпом.

## Запуск

```
npm install
npm run dev
```

Откройте http://localhost:3000

## Сборка

```
npm run build
```

## Где что

- `src/ScheduleModal.tsx` — окно расписания
- `src/utils/fernhollow.ts` — расписание (`WEEKLY_SCHEDULE`), время Астаны, звуки
- `src/index.css` — стили
- `public/` — движок долины и ресурсы
